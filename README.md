# 林间 — 个人主页

一个无需构建工具的静态个人主页，适合用 GitHub Pages 发布。

## 发布到 GitHub Pages

1. 将本目录内容上传到 GitHub 仓库的根目录。
2. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，保存后等待 GitHub Pages 发布。

如果要用作 `用户名.github.io` 主站，请将仓库命名为 `用户名.github.io`。

## 个性化

编辑 `index.html` 中的姓名、介绍、近况和邮件地址。页面字体使用 Google Fonts，字体无法加载时会回退到系统字体。
